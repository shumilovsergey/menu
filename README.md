# Menu

![cover](/build/web/baner.webp)

Это главное Меню, которое собрало в себе все приложения моей экосистемы.

## Задачи

- Передает пользовательскую сессию между приложениями, избавляя от необходимости повторной аутентификации.

- Следит за доступностью приложений и не позволяет пользователю перейти в недоступный сервис

- Является информационным центром экосистемы
